# Release Radar V1 brand direction

These raster drafts record the owner-approved V1 direction for Release Radar By Rekon Labs. They are design references, not production-ready app assets.

## Selected drafts

- `release-radar-icon-v1.png` — five work tiles on a segmented orbit, with one cyan tile identified by a violet-to-cyan scan. The icon uses a deep graphite-navy surface, visible indigo inactive tiles, and a restrained modern visual weight.
- `release-radar-lockup-v1.png` — primary horizontal lockup using the selected icon, the technical/architectural `Release Radar` wordmark, and tracked uppercase `BY REKON LABS` attribution.

The drafts were generated with the built-in image-generation tool and selected through owner-directed visual iteration. The final wordmark lettering must be recreated deterministically rather than extracted from generated raster text.

## Next-phase production task

1. Recreate the selected icon and wordmark as deterministic vector artwork.
2. Identify or license the production typeface, or draw the custom wordmark outlines.
3. Preserve the approved wording and hierarchy: `Release Radar` over `BY REKON LABS`.
4. Produce light- and dark-background horizontal lockups.
