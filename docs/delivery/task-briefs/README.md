# Active task briefs

Only briefs for current work remain here. GitHub issues own work status and useful
results; a brief does not authorize actions by its presence. Before removing an
inactive brief, extract still-valid missing requirements into the owning current
specification and missing architectural decisions into ADRs, then repair references
and retire its catalog identity. Git retains the historical versions.
